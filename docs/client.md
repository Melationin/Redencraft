# 极轻量调试客户端

运行 `build-jemalloc/Release/redstone_client.exe`。Windows 原生侧栏、系统 OpenGL 1.1 和 WIC PNG 解码，无 SDL、Qt、浏览器、材质包管理器或网络连接。Release 主程序约 1.2 MB；纹理保留在旁边的 `assets` 文件夹。客户端直接使用同一个 C++ 模拟核心，暂停时也可编辑。

## 操作

| 操作 | 输入 |
|---|---|
| 锁定指针 / 转动视角 | 点击视图或“进入”；锁定后直接移动鼠标 |
| 释放指针 | Esc；切出窗口也会自动释放 |
| 创造飞行 | WASD；Space 上升，Shift 下降，Ctrl 加速 |
| 选择快捷栏物品 | 滚轮或数字 1–9 |
| 打开 / 关闭创造背包 | E；点击物品放入当前快捷栏格，底部可选目标格 |
| 准星破坏 | 左键；按住重复破坏 |
| 准星放置 | 右键；按住重复放置；最大交互距离 5 格 |
| 取物 | 中键，优先选中快捷栏中已有的同类物品 |
| 连续运行 / 暂停 | 侧栏按钮，或视图内 P |
| 单步一游戏刻 | 侧栏按钮，或视图内 F |
| 调整目标速度 | 1 / 5 / 10 / 20 ticks/s |
| 观察邻居与形状更新 | 勾选“记录更新轨迹”，侧栏保留最近 120 条 |

启动时为暂停的演示场景：点击“触发侦测器”，然后单步两次或连续运行，即可观察侦测器与向上的粘性活塞。场景也展示了 16 色地毯、玻璃、蜂蜜、音符盒与 TNT。地毯、四种铁轨和本批方块在放置列表中直接按注册名选择；铁轨放置后由核心的 `onPlace` 自动连接。状态栏显示方块与实体数量，简单实体以碰撞盒颜色的调试立方体绘制（TNT 红色、矿车灰蓝、物品按物品名着色）。

珊瑚扇物品点水平支撑面时使用地面形式，点方块侧面时切换为相应的墙上珊瑚扇，朝向外侧并检查侧面支撑。不可直接覆盖已有方块。活塞和侦测器依据视线决定放置朝向。Esc 在视图中释放指针，不再作为关闭窗口的对话框快捷键。

地毯按 26.1 Java 源码实现：厚度 1/16，不导电，下方任何非空气方块均可支撑；失去支撑后生成对应颜色的真实物品实体；可被普通活塞推动或粘性活塞拉动。羊毛地毯的推动反应为 NORMAL，不能与苔藓地毯的 DESTROY 混淆。

## 纹理来源与构建

纹理按照用户指定，提取自本机 `D:/Release 2.7.3/Release 2.7.3/.minecraft/versions/26.2优化/26.2优化.jar`。纹理版本不改变 26.1 模拟逻辑。只提取本批所需的 59 张 PNG；地毯直接使用原版相应颜色的羊毛纹理，铁轨包含普通/动力/探测/激活及其点亮状态和弯道纹理。

```powershell
./scripts/import-textures.ps1 -ClientJar 'D:/Release 2.7.3/Release 2.7.3/.minecraft/versions/26.2优化/26.2优化.jar'
cmake --build build-jemalloc --config Release --target redstone_client -j 6
./build-jemalloc/Release/redstone_client.exe
```

CMake 默认在 Windows 构建客户端，可用 `-DREDSTONE_BUILD_CLIENT=OFF` 关闭。构建后自动复制纹理到可执行文件旁的 `assets` 文件夹；移动程序时同时带上该目录。加载缺失纹理时显示紫黑格，不伪装成已加载的原版纹理。

## 限制与验证

- 客户端采用创造模式式的鼠标和快捷栏操作，放置通过核心形状更新与 `setBlock` 修改世界；仍未实现完整玩家碰撞、物品堆叠/拖拽、完整物品交互、生存模式和联网。创造背包目前是单击选物到当前格的简化交互，不是完整原版背包实现。玩家不能拾取物品实体。
- 使用原版纹理和核心的盒形状；不解析完整 Minecraft JSON 模型、资源包、动态纹理、光照和透明排序。草地颜色采用固定调试色，活塞以真实方块实体进度显示，未支持方块显示缺失纹理。铁轨按平面/坡道厚度和形状选择纹理；简单实体只绘制碰撞盒，不使用实体模型。
- “读取存档”当前读取主世界 region 目录，标准高度 [-64, 320)，并加载其中所有完整区块；同步读取，大地图可能较慢。当前阶段仍不保存文件（目标形态是完整读写，见 [AGENTS.md](../AGENTS.md) 第 1 节）。水和流体刻当前不参与模拟；简单实体随存档导入并参与刻，其他实体不参与。加载存档后禁用固定坐标的演示触发按钮。
- 已检查新版实际原生窗口、第一人称视图和快捷栏，背包通过隐藏渲染预览检查。用户中止电脑操作后未继续操作窗口；锁定后的完整鼠标/飞行交互未完成现场验证。读取存档按钮尚未通过实际存档的 UI 流程验证。
- 八组 CTest 全部通过，包括快捷栏切换/循环、背包选物、墙上珊瑚扇支撑与放置、地毯复制和更新顺序轨迹；新增 `entity` 组覆盖简单实体、铁轨和 NBT 导入。图中地毯复制已另行运行原版 26.1 服务端对比，见 `validation/vanilla26_1/README.md`；简单实体和铁轨尚未做真实服务端差分。
